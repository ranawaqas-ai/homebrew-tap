# Homebrew tap

```sh
brew install --cask ranawaqas-ai/tap/lafz-prompter
brew install --cask ranawaqas-ai/tap/bol
```

[Lafz Prompter](https://lafz.waqasrana.space) is a free teleprompter that sits under the MacBook notch.

[Bol](https://bol.waqasrana.space) is voice dictation that types where you are typing.

Both apps update themselves, so `brew upgrade` is only needed for a fresh install of a newer version.
